## Featured Data Engineering Project

### [Places Ratings — Business Discovery Lakehouse](https://github.com/cpomaresnina/Places_Ratings)

Built an API-to-dashboard pipeline to explore business segments in La Paz and El Alto, Bolivia. Processed **315 API responses and 3,272 establishment appearances into 1,314 distinct business snapshots**, with traceable transformations, idempotent Delta loads and a dimensional analytical model.

**Stack:** Python · Google Places API · Amazon S3 · Databricks · Spark SQL · Delta Lake · Unity Catalog · AI/BI Dashboards.

**Focus:** data quality, grain definition, repeatable ingestion, dimensional modeling and evidence-based analysis. The findings challenged the original commercial assumption rather than being forced to confirm it.
